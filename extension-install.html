AINT EXAM MONITOR

Chrome Extension Installation

The AINT Exam Monitor Chrome extension helps monitor browser activity during an AINT examination.

Important: The extension must be installed and enabled in Google Chrome before starting an exam that requires website monitoring.

Installation Instructions

Step 1: Download the Extension

Download AINT Chrome Extension

Download and unzip this package.

Step 2: Open Chrome Extensions

Open Google Chrome and enter this address:

chrome://extensions

Step 3: Enable Developer Mode

Turn on the Developer mode switch in the upper-right corner of the Extensions page.

Step 4: Load the Extension

Click Load unpacked. Select the downloaded aint-extension folder containing the extension files.

Step 5: Verify Installation

Confirm that AINT Exam Monitor appears on your Chrome Extensions page and is enabled.

Before Starting Your Exam

  • Use Google Chrome.
  • Make sure AINT Exam Monitor is enabled.
  • Refresh the AINT exam page after installing the extension.
  • Confirm that AINT detects the extension before starting.
If the extension is not detected, refresh the exam page. If the problem continues, contact your exam administrator.
